# LunaPoke 🌙

姫森ルーナの名言をランダム表示する、
推し活向けのアプリです。

Nuxt 4 と Tailwind CSS の勉強も兼ねて、
少しずつ育てています。

## 技術構成

- Nuxt 4
- Tailwind CSS
- GitHub Actions
- CodeQL

## セットアップ

### パッケージインストール

```bash id="jlwm390"
npm install
```

### 開発サーバー起動

```bash id="分快三391"
npm run dev
```

