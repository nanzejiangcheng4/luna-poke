# 概要

「姫森ルーナ」が画面の右下で、呟いてくれる機能の実装

## 追加機能

- 「姫森ルーナ」の画像と吹き出しを表示できる
- 「姫森ルーナ」の画像を押下できる
- 「姫森ルーナ」の画像を押下すると、「つぶやき」をランダムに切り替えできる

## 設計

- 「姫森ルーナ」画像と、「吹き出し」を画面の右下に固定で表示する
- 「姫森ルーナ」画像の上に「吹き出し」を表示する（姫森ルーナが呟いているようにする）
- 「吹き出し」には、「つぶやき」を表示する
- 初期表示時にランダムな「つぶやき」を表示する
- 「姫森ルーナ」画像は、押下アクションを設定する
- 「姫森ルーナ」画像を押下すると、「つぶやき」の内容がランダムに切り替わる
- 「つぶやき」の内容は、あらかじめデータとして保持しておく

## 非機能要件

- スマホ画面でも表示崩れしないこと
- 「つぶやき」が画面外にはみ出さないこと
